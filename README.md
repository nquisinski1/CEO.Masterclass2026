# Masterclass A. Charly

Landing page independente para uma masterclass focada em conversao de registro.

## Objetivo

Fazer a pessoa entrar, entender rapidamente o valor da masterclass e completar o registro.

## Entrega

- `src/index.html`: pagina estatica principal.
- `src/styles.css`: design responsivo e sistema visual.
- `src/script.js`: contador, interacoes e validacao leve do formulario.
- `docs/conversion-blueprint.md`: arquitetura de conversao aprendida a partir das referencias.
